# D'où viennent les modèles 3D

- **Modèles 3D** (`public/modeles/`) : générés avec l'API Tripo (abonnement payant du parent : modèles privés, usage libre), par `scripts/generer-modeles.mjs`.
- **Images de départ** (`content/modeles/images/`) : `maison-du-personnage.png` et `forain-chamboule.png` ont été dessinées avec Meshy (plan gratuit, licence CC BY 4.0 : « images générées avec Meshy, meshy.ai »). Les prochaines images seront faites avec Tripo.
